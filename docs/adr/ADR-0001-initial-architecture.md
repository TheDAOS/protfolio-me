# Architecture record: existing site and retrofit

- Date: 2026-11-10
- Status: Observed baseline, not a new product decision

The existing application is a Next.js single-page personal portfolio using React, Tailwind, Framer Motion, Lottie and Vercel integrations. Yggdrasil context, skills and verification tooling were added to aid future work without changing the site's behavior. Preserve existing hosting and telemetry choices until the owner directs otherwise; prefer free local development tools and never push without explicit approval.
